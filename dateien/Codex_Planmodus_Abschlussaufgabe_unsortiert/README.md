# Projektübersicht: KI-Einstiegsangebot für Pflegeeinrichtungen

Die Dateien gehören zu einem Projekt: ein einfaches, sicheres KI-Einstiegsangebot (Workshop, Checkliste, Nachbereitung) für Pflegeeinrichtungen und soziale Träger. Sie sind nach Thema sortiert, nicht nach Herkunft.

## Ordner

| Ordner | Inhalt |
|---|---|
| `01_Strategie_und_Produkt` | Ziel, Produktidee und Hintergrundrecherche |
| `02_Meetings_und_Aufgaben` | Meetingnotizen, Transkript, Aufgabenlisten und interne nächste Schritte |
| `03_Angebot_und_Preise` | Angebotsentwurf, Angebotsbausteine, Preisliste und Paketstruktur |
| `04_Kunden_und_Anfragen` | Kundenanfragen, typische Kundenfragen und Follow-up-Mail |
| `05_Workshop_und_Trainer` | Folienstruktur, Rollenprofil und Bewerbung für die Trainerrolle |
| `06_Datenschutz_und_Regeln` | Datenschutz-Checkliste, interne KI-Regeln, Risiken und Grenzen |
| `07_Marketing_und_Kommunikation` | Landingpage-Ideen, LinkedIn-Entwurf und FAQ |
